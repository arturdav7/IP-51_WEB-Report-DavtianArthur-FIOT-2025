Завдання №7 — Навігація по DOM (ul#categories)

Умова: Порахувати і вивести в консоль кількість категорій в ul#categories. Для кожного li.item вивести текст заголовку (h2) і кількість вкладених li. Використати forEach() і навігацію по DOM.


Програмний код:

const categories = document.querySelectorAll('#categories li.item');

console.log(`Number of categories: ${categories.length}`);

categories.forEach(item => {
  const title    = item.querySelector('h2').textContent;
  const count    = item.querySelectorAll('li').length;
  console.log(`Category: ${title}`);
  console.log(`Elements: ${count}`);
});

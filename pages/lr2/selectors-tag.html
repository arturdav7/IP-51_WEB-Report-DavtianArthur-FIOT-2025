Селектори тегу

Селектор тегу застосовується до всіх елементів певного типу (наприклад body, h1, p, main, section).

CSS (селектор тегу)

body{
  margin:0;
  font-family:system-ui,-apple-system,"Segoe UI",Roboto,Arial,sans-serif;
  color:var(--ink);
  line-height:1.65;
  background: ...;
}

h1,h2,h3{
  line-height:1.15;
  margin:0 0 10px;
}

p{
  margin:0 0 10px;
  color:var(--ink);
}

HTML (де застосовано)

<body>
  <header class="container site-header">...</header>

  <main>
    <section id="hero" class="hero container">
      <h1 id="hero-title">...</h1>
      <p class="lead">...</p>
    </section>
  </main>
</body>

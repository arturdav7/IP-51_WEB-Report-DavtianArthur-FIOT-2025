Контрольні питання

  1. Для чого використовують CSS?
    Для оформлення зовнішнього вигляду HTML-елементів (кольори, шрифти, відступи, розміщення, адаптивність).
  2. Що таке селектор?
    Правило, яке визначає, до яких елементів застосовуються CSS-властивості.
  3. Різниця між селектором тегу, класу та ID?
    Тег — для всіх елементів типу (p), клас — для групи (.card), ID — для одного унікального елемента (#hero).
  4. Що таке каскадність?
    Принцип CSS, коли фінальний стиль залежить від порядку правил, специфічності та успадкування.
  5. Що таке специфічність?
    “Вага” селектора: #id сильніший за .class, а .class сильніший за tag.

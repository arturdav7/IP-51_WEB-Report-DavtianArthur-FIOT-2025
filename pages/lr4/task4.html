Завдання №4 — Функція getShippingMessage()

Умова (варіант парний): Оголосити функцію getShippingMessage(country, price, deliveryFee), яка повертає рядок з повідомленням про доставку: "Shipping to <country> will cost <totalPrice> credits", де totalPrice = price + deliveryFee.


Програмний код:

function getShippingMessage(country, price, deliveryFee) {
  let totalPrice = price + deliveryFee;
  return `Shipping to ${country} will cost ${totalPrice} credits`;
}

// Виклики функції:
console.log( getShippingMessage("Ukraine", 500, 50)   );
console.log( getShippingMessage("Germany", 1200, 150) );
console.log( getShippingMessage("France",  800, 95)   );

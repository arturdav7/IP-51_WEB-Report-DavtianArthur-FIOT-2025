Селектори ідентифікатора (ID)

Селектор ідентифікатора застосовується до одного елемента з конкретним значенням атрибута id. У проєкті ID використовуються для навігації по секціях, а також (для ЛР2) — для точкового стилювання.

CSS (селектори ID)

#hero-title{
  text-shadow: 0 8px 22px rgba(2,6,23,.20);
}

#contacts{
  border: 1px solid rgba(59,130,246,.22);
}

HTML (де застосовано)

<section id="hero" class="hero container" aria-labelledby="hero-title">
  <h1 id="hero-title">Футбольні легенди...</h1>
</section>

<section id="contacts" class="container" aria-labelledby="contacts-title">
  <h2 id="contacts-title">Контакти</h2>
  ...
</section>

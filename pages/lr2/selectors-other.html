Інші селектори

У проєкті застосовано універсальний селектор, дочірній селектор, псевдокласи та псевдоелементи. Це дозволяє зробити інтерфейс більш “живим” (hover-ефекти, glow-рамки, анімації).

Приклад 1 — універсальний селектор *

*{ box-sizing: border-box; }

Приклад 2 — дочірній селектор >

.card > *{ position:relative; z-index:1; }

Приклад 3 — псевдоклас :hover

.menu a:hover{
  background:rgba(255,255,255,.14);
  transform: translateY(-1px);
}

Приклад 4 — псевдоелементи ::before та ::after

.card::before{ ... }
.card::after{ ... }

.menu a::after{
  content:"";
  height:2px;
  background: linear-gradient(90deg, var(--brand), var(--brand-2));
}

Приклад 5 — селектор атрибута

input[type="email"]{
  border-color: rgba(34,197,94,.35);
}

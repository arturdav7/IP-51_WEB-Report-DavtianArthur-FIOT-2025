Завдання №6 — Подвоїти список

Умова: Створити розмітку з текстом та маркованим списком. Натиснувши кнопку "Подвоїти", збільшити значення у кожному елементі списку у 2 рази. Повторний натиск також подвоює.


Програмний код:

const doubleBtn = document.querySelector('#doubleBtn');

doubleBtn.addEventListener('click', () => {
  const items = document.querySelectorAll('#numList li');
  items.forEach(li => {
    li.textContent = li.textContent * 2;
  });
});

Результат:

  • 1
  • 4
  • 8
  • 16
  • 20
  • 30

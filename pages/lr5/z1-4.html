Завдання №1 — Варіант 4: Концерти (фільтрація + сортування)

Умова: З об'єкту concerts отримати масив міст. Прибрати міста, в яких концерт вже пройшов. Відсортувати у хронологічному порядку. Застосувати стрілочні функції.

Очікуваний результат: ["Одеса", "Умань", "Харків"]


Програмний код:

const concerts = {
  Київ:         new Date("2020-04-01"),
  Умань:        new Date("2025-07-02"),
  Вінниця:      new Date("2020-04-21"),
  Одеса:        new Date("2025-03-15"),
  Хмельницький: new Date("2020-04-18"),
  Харків:       new Date("2025-07-10"),
};

const now = new Date();

const result = Object.entries(concerts)
  .filter(([city, date]) => date > now)       // лише майбутні
  .sort(([, a], [, b]) => a - b)              // хронологічно
  .map(([city]) => city);                     // лише назви міст

console.log(result); // ["Одеса", "Умань", "Харків"]

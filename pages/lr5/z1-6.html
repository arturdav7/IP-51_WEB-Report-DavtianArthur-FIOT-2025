Завдання №1 — Варіант 6: Медикаменти (знижка 30%)

Умова: Написати функцію, яка приймає масив об'єктів і повертає новий масив об'єктів, у якому є знижка 30% на всі медикаменти, ціна яких перевищує 300 грн. Надати id для кожного медикамента.


Програмний код:

const medicines = [
  { name: "Noshpa",       price: 170 },
  { name: "Analgin",      price: 55  },
  { name: "Quanil",       price: 310 },
  { name: "Alphacholine", price: 390 },
];

const applyDiscount = arr => arr.map((item, index) => ({
  id:    index + 1,
  name:  item.name,
  price: item.price > 300
    ? +(item.price * 0.7).toFixed(2)  // знижка 30%
    : item.price,
}));

const result = applyDiscount(medicines);
console.log(result);

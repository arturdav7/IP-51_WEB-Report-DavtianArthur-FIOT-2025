}

2) Контур (outline) + фокус

input:focus, textarea:focus{
  border-color: rgba(59,130,246,.55);
  box-shadow: 0 0 0 4px rgba(59,130,246,.18);
}

3) Демонстрація таблиці (приклад у звіті)

Таблиця створена у звітному документі для демонстрації CSS-властивостей таблиць.

<table class="demo-table">
  <thead>
    <tr><th>Елемент</th><th>Приклад</th></tr>
  </thead>
  <tbody>
    <tr><td>.btn</td><td>Кнопка (градієнт)</td></tr>
    <tr><td>.card</td><td>Картка досягнення</td></tr>
    <tr><td>#contacts</td><td>Секція контактів</td></tr>
  </tbody>
</table>
.demo-table{
  width:100%;
  border-collapse:collapse;
  margin-top:10px;
  background:rgba(255,255,255,.92);
  border:1px solid rgba(15,23,42,.12);
  border-radius:12px;
  overflow:hidden;
}

.demo-table th, .demo-table td{
  padding:10px 12px;
  border-bottom:1px solid rgba(15,23,42,.10);
  text-align:left;
}

.demo-table thead th{
  background:rgba(59,130,246,.10);
}

.cardКартка досягнення

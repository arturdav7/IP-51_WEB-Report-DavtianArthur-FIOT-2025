Завдання №4 — Зменшити / Збільшити квадрат

Умова: Створити розмітку з текстом, блоком (div) та двома кнопками. Кнопка "Зменшити" зменшує квадрат на 15px, "Збільшити" — збільшує на 15px. Повторний натиск продовжує змінювати розмір.


Програмний код:

const square      = document.querySelector('#square');
const decreaseBtn = document.querySelector('#decreaseBtn');
const increaseBtn = document.querySelector('#increaseBtn');

decreaseBtn.addEventListener('click', () => {
  const size = parseInt(square.style.width) - 15;
  if (size > 15) {
    square.style.width  = size + 'px';
    square.style.height = size + 'px';
  }
});

increaseBtn.addEventListener('click', () => {
  const size = parseInt(square.style.width) + 15;
  square.style.width  = size + 'px';
  square.style.height = size + 'px';
});

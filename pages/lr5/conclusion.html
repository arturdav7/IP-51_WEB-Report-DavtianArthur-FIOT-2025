Висновки по роботі

У ході виконання лабораторної роботи №5 були отримані практичні навички роботи з об'єктами, callback-функціями, стрілочними функціями та перебираючими методами масивів у JavaScript.

У завданні №1 (варіант 2) реалізована функція getProductDetails з двома колбеками — successCallback та errorCallback. Закріплено концепцію передачі функцій як аргументів.

У завданні №1 (варіант 4) опрацьовано роботу з об'єктом через Object.entries(), фільтрацію за датою методом filter(), сортування через sort() та отримання лише ключів через map(). Застосовано стрілочні функції.

У завданні №1 (варіант 6) реалізована функція зі знижкою 30% для товарів дорожче 300 грн із використанням стрілочної функції та методу map(). Додано генерацію id через індекс.

У завданні №1 (варіант 8) реалізована функція-конструктор Storage з методами керування складом товарів — getItems(), addItems(), removeItem().

У завданні №1 (варіант 9) підраховано кількість тегів з масиву об'єктів через метод reduce() у поєднанні з forEach().

У завданні №1 (варіант 10) реалізована функція перевірки правильності дужок через стек — класичний алгоритм з використанням циклу for...of.

У завданні №2 (варіант 2) використано метод some() для перевірки умови хоча б на одному елементі масиву.

У завданні №2 (варіант 4) використано метод map() для побудови нового масиву квадратів вхідних чисел.

У завданні №2 (варіант 6) використано метод sort() зі стрілочною функцією-компаратором для сортування масиву об'єктів за числовим полем.

У завданні №2 (варіант 7) реалізований клас Calculator з підтримкою ланцюжкового виклику методів (method chaining) через повернення this. Опрацьовано обробку виключень через try/catch.

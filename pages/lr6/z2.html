Завдання №2 — SWAP ME

Умова: Створити розмітку з текстом, кнопкою та двома інпутами. Після натискання кнопки "SWAP ME" здійснюється обмін вмістом між двома інпутами.


Програмний код:

const btn  = document.querySelector('#swapBtn');
const inp1 = document.querySelector('#inp1');
const inp2 = document.querySelector('#inp2');

btn.addEventListener('click', () => {
  [inp1.value, inp2.value] = [inp2.value, inp1.value];
});

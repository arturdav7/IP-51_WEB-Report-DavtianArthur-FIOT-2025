Завдання №2 — Варіант 4: Квадрати елементів (map)

Умова: Дано масив чисел [1, 2, 3, 4, 5]. Створити новий масив, що містить квадрати кожного елементу.

Очікуваний результат: [1, 4, 9, 16, 25]


Програмний код:

const numbers = [1, 2, 3, 4, 5];

const squares = numbers.map(n => n ** 2);

console.log(squares); // [1, 4, 9, 16, 25]

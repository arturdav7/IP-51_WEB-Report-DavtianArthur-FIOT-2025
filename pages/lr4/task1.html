Завдання №1 — Чверті години

Умова (варіант парний): Збережіть введене значення часу (год:хвил) (використати метод prompt()) у змінну. Вивести це значення у Console, використовуючи шаблонний рядок. Перевірити до якої чверті години відноситься введене значення. Відповідь вивести за допомогою alert().

Наприклад: при введенні 10:30 виведе «Перша чверть години»


Програмний код:

let timeInput = prompt("Введіть час у форматі ГГ:ХВ (наприклад 10:30):");

if (timeInput === null || timeInput.trim() === "") {
  alert("Значення не введено!");
} else {
  console.log(`Введений час: ${timeInput}`);
if (!/^\d{1,2}:\d{2}$/.test(timeInput)) {
  alert("Невірний формат! Введіть час у форматі ГГ:ХВ");
  return;
}
  let parts   = timeInput.split(":");
  let minutes = parseInt(parts[1]);

  let quarter;
  if      (minutes >= 0  && minutes <= 14) quarter = "Перша чверть години (0–14 хв)";
  else if (minutes >= 15 && minutes <= 29) quarter = "Друга чверть години (15–29 хв)";
  else if (minutes >= 30 && minutes <= 44) quarter = "Третя чверть години (30–44 хв)";
  else                                     quarter = "Четверта чверть години (45–59 хв)";

  alert(quarter);
}

Після натискання введіть час у форматі 10:30 — результат з'явиться в alert() та у Console (F12).

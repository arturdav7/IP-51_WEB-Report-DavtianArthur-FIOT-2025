Завдання №3 — Авторизація User1 / User2 / User3

Умова (варіант парний): Є декілька користувачів User1, User2, User3 з відповідними паролями. Написати код, який запитуватиме логін (через prompt) і виводить результат в консоль за допомогою шаблонного рядка. Якщо User1/2/3 — запитати пароль; при успіху — alert("Hello, UserX"). Якщо нічого не ввели або Cancel — prompt знову просить логін. В іншому випадку — alert("I don't know you").


Програмний код:

const user1Login = "User1",  user1Password = "pass1";
const user2Login = "User2",  user2Password = "pass2";
const user3Login = "User3",  user3Password = "pass3";

let login = prompt("Введіть логін (User1 / User2 / User3):");

// якщо Cancel або порожнє — повторюємо
while (login === null || login.trim() === "") {
  login = prompt("Логін не введено. Спробуйте ще раз:");
}

console.log(`Введений логін: ${login}`);

if (login === user1Login || login === user2Login || login === user3Login) {
  let password = prompt(`Введіть пароль для ${login}:`);
  let correct  = login === user1Login ? user1Password
               : login === user2Login ? user2Password
               :                        user3Password;
  if (password === correct) {
    alert(`Hello, ${login}`);
  } else {
    alert("Невірний пароль!");
  }
} else {
  alert("I don't know you");
}

Паролі для тесту: User1 → pass1 | User2 → pass2 | User3 → pass3

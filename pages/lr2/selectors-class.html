Селектори класу

Селектор класу застосовується до елементів, які мають атрибут class. У проєкті активно використовуються класи для структури, меню, кнопок, карток та блоків.

CSS (селектори класу)

.container{
  width:min(var(--container), 100%);
  margin:0 auto;
  padding:18px 16px;
}

.site-header{
  display:flex;
  align-items:center;
  justify-content:space-between;
  position:sticky;
  top:0;
  background:rgba(7,27,18,.55);
}

.menu a{
  display:inline-block;
  color:rgba(255,255,255,.88);
  padding:8px 12px;
  border-radius:999px;
}

.btn{
  display:inline-flex;
  padding:10px 14px;
  border-radius:12px;
  background: linear-gradient(90deg, var(--brand), var(--brand-2));
  color:#fff;
}

HTML (де застосовано)

<header class="container site-header">
  <a class="logo" href="#hero">R9 & Zidane</a>

  <nav>
    <ul class="menu">
      <li><a href="#hero">Головна</a></li>

    </ul>
  </nav>
</header>

Висновки по роботі

У ході виконання лабораторної роботи №4 були отримані практичні навички роботи з основними конструкціями мови JavaScript у HTML-документах.

У завданні №1 опрацьовано метод prompt() для введення даних, шаблонні рядки для виведення у console.log(), а також розгалуження if / else if для визначення чверті години.

У завданні №2 закріплено конструкцію switch-case з обов'язковим блоком default для обробки невалідного вводу користувача.

У завданні №3 реалізована авторизація кількох користувачів із використанням циклу while для повторного запиту логіна та тернарного оператора для визначення пароля.

У завданнях №4–6 опрацьовано оголошення та виклик функцій, робота зі шаблонними рядками, арифметичними операціями та методами масивів concat() і slice().

У завданні №7 (варіант 4) закріплена робота з двома паралельними масивами, побудова нового масиву за формулою, пошук максимального елемента та його перестановка. Реалізовано класичний алгоритм сортування методом бульбашки.

У завданні №8 продемонстровано роботу з двовимірними масивами та методами flat() і splice() для вставки елемента.

У завданні №9 (варіант 4) реалізовано текстовий редактор з використанням атрибута contenteditable, методу document.execCommand() для форматування та API window.getSelection() для роботи з виділеним текстом.

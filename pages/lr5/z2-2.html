Завдання №2 — Варіант 2: Перевірка віку (some)

Умова: Дано масив об'єктів. Перевірте, чи є хоча б один об'єкт з віком менше 20 років.

Очікуваний результат: true


Програмний код:

const people = [
  { name: 'John', age: 27 },
  { name: 'Jane', age: 31 },
  { name: 'Bob',  age: 19 },
];

const hasYoung = people.some(person => person.age < 20);

console.log(hasYoung); // true

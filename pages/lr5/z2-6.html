Завдання №2 — Варіант 6: Сортування за віком (sort)

Умова: Відсортувати масив об'єктів за віком у порядку зростання.

Очікуваний результат: [{name:"Bob",age:19}, {name:"John",age:27}, {name:"Jane",age:31}]


Програмний код:

const users = [
  { name: 'John', age: 27 },
  { name: 'Jane', age: 31 },
  { name: 'Bob',  age: 19 },
];

const sorted = [...users].sort((a, b) => a.age - b.age);

console.log(sorted);
// [{name:"Bob",age:19},{name:"John",age:27},{name:"Jane",age:31}]
